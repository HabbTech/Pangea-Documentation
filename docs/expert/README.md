# Expert Mode Guides

These guides cover the screens Expert Mode adds. To turn it on, go to **Settings → App Settings → Expert Mode**. See [Expert Mode](../settings.md#expert-mode) for what changes.

> [!WARNING]
> Expert settings write straight to the radio. A wrong setting can cut your radio off from everyone else. Change only what you understand.

| Guide | What's in it |
|---|---|
| [Connecting Radios](connecting-radios.md) | The Connect tab, Bluetooth, Wi-Fi and USB connections, switching radios, pairing settings |
| [Nodes](nodes.md) | The node list, filters, node details, logs and trace routes |
| [Map & Waypoints](map.md) | The Map tab, filters, offline maps, waypoints, geofences and coverage estimates |
| [Signal Meter](signal-meter.md) | What the signal bars mean and how they're worked out |
| [Telemetry & Sensors](telemetry.md) | Battery, environment, air quality and power reports, and their settings |
| [Local Mesh Discovery](local-mesh-discovery.md) | Find which radio settings people near you are using |
| [Firmware Updates](firmware-updates.md) | Update, repair or erase your radio's firmware |
| [MQTT](mqtt.md) | Link your mesh to an internet server |
| [TAK](tak.md) | Use your radio with iTAK and other TAK apps |
| [Apple Watch](apple-watch.md) | Find a radio on foot with the Watch compass |
| [Units & Language](units-and-locale.md) | How temperatures, distances and dates are shown |
| [Logs & File Storage](logs-and-storage.md) | Read and export logs, send them to us, and manage stored files |
