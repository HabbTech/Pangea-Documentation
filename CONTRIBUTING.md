# Contributing

Thanks for helping improve the Pangea docs.

## Ways to help

- **Fix something wrong or unclear.** Open a pull request, or an issue if you're not sure of the fix.
- **Report a radio.** Tried Pangea with a radio not marked "Tested" in [Supported Hardware](docs/supported-hardware.md)? Open a **Hardware report** issue.
- **Report a bug in the app.** Use the **Bug report** issue template.

## Writing style

- Short sentences. Plain words. Say what to tap, in **bold**, in the order you tap it.
- Use the names exactly as they appear in the app.
- Tables for comparisons and settings, numbered lists for steps.
- One topic per page. Link to other pages instead of repeating them.
- Use GitHub alerts (`> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`) sparingly.

## Pull requests

1. Fork the repo and create a branch.
2. Make your change and preview it on GitHub.
3. Check that links work.
4. Open a pull request describing what changed and why.
