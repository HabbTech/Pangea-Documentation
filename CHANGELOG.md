# Changelog

All notable changes to Pangea are listed here.

## [Unreleased]

### Added
- Profiles: photo, emoji, color and display name, shared with Pangea users
- Private nicknames
- Personal `@codes` for starting private chats
- Private group chats with invite links and QR codes
- @mentions in groups
- Simple radio pairing with automatic region setup
- Expert Mode and battery modes
- Contacts: save people from their profile, and find them in New Message and group invites
- Invite people to a group by their code or QR code
- Delete private chats and leave groups from the Chats list (swipe on iPhone, right-click on Mac)
- Everyone Nearby pinned to the top of Chats, with notifications off by default and a bell to turn them on
- Radios switch to pairing without a code after the first connection
- "Not delivered" status with Try Again for messages that get no answer

### Removed
- Analytics, crash reporting and session recording
