# Security Policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**.

Include:

- What the issue is and what an attacker could do with it
- Steps to reproduce
- App version (**Settings → About**), device, OS version, and radio firmware

We'll confirm we got your report within a few days and keep you updated until it's fixed.

## Scope

| In scope | Out of scope |
|---|---|
| The Pangea iOS and macOS apps | The Meshtastic firmware and protocol (report those to [Meshtastic](https://github.com/meshtastic/firmware/security)) |
| Pangea invite links, codes and profile sharing | Physical access to an unlocked device |
| How Pangea stores data on your device | Radio jamming or interference |

## Supported versions

Only the latest TestFlight build gets security fixes while Pangea is in testing.
